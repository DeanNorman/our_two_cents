```

Abigail: *checks bank balance* *does mental math* "Uh, sure I guess?"
Dean: *feels guilty* *checks balance later and worries*
```

```
Dean: *opens dashboard* "We have R1,200 left in Shopping this month"

Abigail: *opens same dashboard* "Yeah, go for it" OR "Let's wait til next month"
```

## ✅ Phase 3 Activities

### One-Time: Budget-Setting Session (90 minutes)

**This is the most important session. Block out 90 minutes.**

#### Part 1: Reality Check - Income (10 min)

```
Dean's monthly salary (after tax):      R_______
Abigail's monthly salary (after tax):   R_______
Other reliable income:                  R_______

TOTAL INCOME:                           R_______
```

This is your Money In. Everything must fit inside this number.

#### Part 2: Lock In Fixed Costs (15 min)

These are numbers you CAN'T easily change month-to-month:

```
Rent/Bond:              R_______
Electricity:            R_______
Water:                  R_______
Internet:               R_______
Insurance (all):        R_______
Medical aid:            R_______
Phone contracts:        R_______
Car payment (if any):   R_______
Other fixed bills:      R_______

TOTAL FIXED:            R_______
```

**These categories don't get budgets. They're just reality.**

(Later, you can optimize these. But for now, accept them.)

#### Part 3: Decide on Savings First (20 min)

**Sam's principle: "Pay yourself first"**

Before you allocate to spending, decide: How much do we want to save per month?

**Decision tree:**

```
Do you have ANY emergency savings? (even R5,000?)
├─ NO → Start with 5% of income
│         Example: R30k income → R1,500/month to savings
│
└─ YES → Do you have 3 months expenses saved?
   ├─ NO → Aim for 10% of income
   │        Example: R30k income → R3,000/month to savings
   │
   └─ YES → Do you have a specific goal? (car, trip, renovation)
      ├─ NO → Aim for 15% of income
      │        Example: R30k income → R4,500/month to savings
      │
      └─ YES → Work backwards from goal
               Example: Need R50k in 10 months → R5,000/month
```

**Your decision:**
```
We will save R_______ per month
```

#### Part 4: Calculate Discretionary Pool (5 min)

```
Total Income:           R_______
Minus Fixed Costs:    - R_______
Minus Savings:        - R_______

= DISCRETIONARY MONEY:  R_______
```

This is what you have to allocate to everything else: groceries, dining, transport, shopping, entertainment, etc.

#### Part 5: Allocate to Flexible Categories (30 min)

Now allocate your discretionary money. Use your Phase 2 averages as starting point.

**Example conversation:**

```
Abigail: "We have R15,000 discretionary. Our Phase 2 averages were:
  - Groceries: R4,500
  - Dining out: R2,800
  - Transport: R2,000
  - Entertainment: R1,200
  - Shopping: R800
  - Other: R400
  Total: R11,700"

Dean: "So we have R3,300 extra?"

Abigail: "Yeah. Where should it go?"

Options:
1. Increase a category that felt too tight
2. Add to savings
3. Create a new category we forgot (gifts, hobbies, etc.)
4. Create a "flex fund" for unexpected stuff
```

**Your budget (example):**

| Category | Phase 2 Average | New Budget | Reasoning |
|----------|----------------|------------|-----------|
| Groceries | R4,500 | R5,000 | Give ourselves buffer |
| Dining Out | R2,800 | R2,500 | Try to reduce slightly |
| Transport | R2,000 | R2,000 | Seems right |
| Entertainment | R1,200 | R1,500 | We want more here |
| Shopping | R800 | R1,000 | Round up for ease |
| Personal (Dean) | - | R2,000 | Make allowance official |
| Personal (Abigail) | - | R2,000 | Equal treatment |
| Flex/Unexpected | - | R1,000 | Buffer for surprises |
| **TOTAL** | **R11,300** | **R15,000** | **Fits discretionary** |

#### Part 6: The Accountability Agreement (10 min)

Now that you have budgets, agree on the new system:

**Dean's new freedoms:**
- "I can spend from my personal allowance (R2,000) however I want, no asking"
- "For purchases in other categories, I check dashboard first"
- "If we have budget left, I can decide yes myself for purchases under R___" (pick: R200? R500?)
- "For bigger purchases, I still discuss with Abigail, but now we both see the same data"

**Abigail's new freedoms:**
- "I also have personal allowance (R2,000) I don't need to justify"
- "I don't have to be the only one watching the money"
- "When Dean asks about a purchase, I can say 'check the dashboard' instead of doing mental math"

**Shared agreements:**
- "We both check dashboard before big purchases"
- "Going over budget isn't a crime - we just discuss why and adjust"
- "If one category is over, we can balance from another category"
- "We review budgets monthly and adjust as needed"

**Write this down and both sign it. Seriously. It makes it real.**

### Daily (30 seconds, different mindset)

**Dean's new habit:**

Before making a discretionary purchase over R___ (whatever amount you agreed):

1. Open dashboard on phone
2. Check category budget: "R1,200 left in Shopping"
3. Decide: Is R500 purchase worth it?
4. If yes and under R500: Buy it, log it, move on
5. If yes and over R500: Text Abigail with the numbers
6. If no: Wait until next month

**Abigail's new habit:**

- Check dashboard weekly instead of daily
- Trust Dean to check before spending
- When Dean asks, check dashboard (not bank balance)
- Make decisions together based on data

### Weekly (30 minutes)

**"The Weekly Recon" (Final Form)**

**1. Check-in (5 min):**
- "How's everyone feeling about spending this week?"
- "Any surprises?"

**2. Category Review (15 min):**
- Go through each flexible category
- Check: on track? over? under?
- Discuss: any adjustments needed?

**3. Wins & Learnings (5 min):**
- What went well?
- What was harder than expected?
- Any aha moments?

**4. Plan ahead (5 min):**
- Any big expenses coming next week?
- Do we need to be careful in any category?
- Any category where we can spend more freely?

### Monthly (60 minutes - First Sunday after payday)

**"The Big Monthly Money Review" (Final Form)**

This is your most important ritual. Make it special.

#### Part 1: Celebrate First (10 min)

**ALWAYS start with wins:**
- "We stayed under budget in 4 out of 7 categories!"
- "We saved R_____ this month!"
- "Dean checked the dashboard 5 times before making decisions!"
- "We didn't fight about money once!"

Celebrate these. Pour wine. High-five. Whatever.

#### Part 2: The Numbers (20 min)

Review the month:

```
Income:              R_______
Fixed Costs:         R_______
Savings:             R_______ (did we hit our goal?)
Discretionary Spent: R_______
Budget:              R_______
Difference:          R_______ (over/under)
```

For each category:

```
Category: Groceries
Budget:   R5,000
Actual:   R4,750
Difference: -R250 (under!)

Why? "We meal-planned better this month"
```

Go through all of them. Understand what happened.

#### Part 3: Adjust Budgets (15 min)

Based on the month's data, adjust budgets if needed:

**Increase budget if:**
- You went over by more than 20%
- It felt punishing or restrictive
- You're making yourselves miserable
- Your life circumstances changed

**Decrease budget if:**
- You were consistently under by 20%+
- The amount feels too easy
- You want to save more

**Keep same if:**
- It felt about right
- You were within 10% of budget

#### Part 4: Plan Next Month (10 min)

- Any big expenses coming? (birthdays, holidays, etc.)
- Do we need to adjust any categories temporarily?
- Are we on track for our savings goal?

#### Part 5: The Money Move (5 min)

**Actually MOVE the savings:**
- Transfer R____ to savings account
- Update your dashboard
- Celebrate that it's done

```javascript
import React from 'react';
import { Wallet, TrendingDown, Calendar } from 'lucide-react';

const OverviewCard = ({ income, spent, budgeted, daysLeft }) => {

    if (percentUsed < 60) return 'text-green-600';

      <div className="flex items-center justify-between mb-6">
        <div>

            {new Date().toLocaleDateString('en-ZA', { month: 'long', year: 'numeric' })}
          </h2>
          <p className="text-gray-600">Our Monthly Budget</p>
        </div>
        <div className="flex items-center gap-2 text-sm text-gray-600">
          <Calendar size={18} />
          <span>{daysLeft} days left</span>
        </div>
      </div>
      
      <div className="grid grid-cols-3 gap-4 mb-6">
        <div className="bg-white rounded-xl p-4 shadow-sm">

          <p className="text-2xl font-bold text-gray-900">
            R{budgeted.toLocaleString()}
          </p>
        </div>

          </p>
        </div>
        
        <div className="bg-white rounded-xl p-4 shadow-sm">
          <div className="flex items-center gap-2 mb-2">
            <TrendingDown size={20} className="text-green-600 rotate-180" />

          <span className="text-gray-700 font-medium">

            {(100 - percentUsed).toFixed(0)}% Remaining
          </span>
        </div>

            }`}
            style={{ width: `${Math.min(percentUsed, 100)}%` }}

      </div>
      
      <div className="flex items-center justify-between pt-4 border-t border-gray-200">
        <p className="text-gray-700">
          Daily budget for remaining days:
        </p>
        <p className="text-xl font-bold text-gray-900">
          R{Math.round(dailyBudget)}
        </p>
      </div>
    </div>
  );
};

export default OverviewCard;
```

**Enhanced Category Card with Budget:**

```javascript
// dashboard/src/components/CategoryCardWithBudget.jsx

import React from 'react';
import { motion } from 'framer-motion';

const CategoryCardWithBudget = ({ category }) => {
  const { 
    icon, 
    displayName, 
    totalSpent, 
    budgetAmount, 
    remaining, 
    percentUsed 
  } = category;
  
  const getColorForPercent = (percent) => {
    if (percent < 60) return 'bg-green-500';
    if (percent < 80) return 'bg-blue-500';
    if (percent < 100) return 'bg-yellow-500';
    return 'bg-coral-500';
  };
  
  const getTextColorForPercent = (percent) => {
    if (percent < 60) return 'text-green-600';
    if (percent < 80) return 'text-blue-600';
    if (percent < 100) return 'text-yellow-600';
    return 'text-coral-600';
  };
  
  const getWarningMessage = (percent, remaining) => {
    if (percent >= 100) {
      return {
        icon: '🛑',
        text: `R${Math.abs(remaining).toFixed(0)} over budget`,
        color: 'text-coral-600'
      };
    }
    if (percent >= 90) {
      return {
        icon: '⚠️',
        text: `R${remaining.toFixed(0)} left - almost there!`,
        color: 'text-yellow-600'
      };
    }
    return null;
  };
  
  const warning = getWarningMessage(percentUsed, remaining);
  
  return (
    <motion.div
      className="bg-white rounded-xl shadow-md p-6 hover:shadow-lg transition-all"
      whileHover={{ scale: 1.02 }}
    >
      <div className="flex items-center justify-between mb-4">
        <div className="flex items-center gap-3">
          <span className="text-4xl">{icon}</span>
          <div>
            <h3 className="text-lg font-semibold text-gray-900">
              {displayName}
            </h3>
            <p className="text-sm text-gray-500">
              R{totalSpent.toFixed(0)} / R{budgetAmount.toFixed(0)}
            </p>
          </div>
        </div>
        
        <div className={`text-2xl font-bold ${getTextColorForPercent(percentUsed)}`}>
          {percentUsed}%
        </div>
      </div>
      
      <div className="w-full bg-gray-200 rounded-full h-3 mb-3">
        <motion.div
          className={`h-3 rounded-full transition-all ${getColorForPercent(percentUsed)}`}
          initial={{ width: 0 }}
          animate={{ width: `${Math.min(percentUsed, 100)}%` }}
          transition={{ duration: 0.8, ease: "easeOut" }}
        />
      </div>
      
      <div className="flex justify-between items-center text-sm">
        <span className="text-gray-600">
          {remaining >= 0 
            ? `R${remaining.toFixed(0)} left`
            : `R${Math.abs(remaining).toFixed(0)} over`
          }
        </span>
        
        {warning && (
          <span className={`font-semibold ${warning.color}`}>
            {warning.icon} {warning.text}
          </span>
        )}
      </div>
    </motion.div>
  );
};

export default CategoryCardWithBudget;
```
